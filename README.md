# Scratch 儿童编程课件

面向约 9–10 岁儿童的 Scratch 游戏编程课件，采用「试玩 → 观察 → 拆解 → 动手 → 改造 → 展示」的教学方式。

每份课件都是独立 HTML 文件，内置课堂试玩、启发式问题、参考积木文字、教师提示与自检清单，无需安装依赖或联网。

## 课程

| 课件 | 学习内容 | 建议安排 |
| --- | --- | --- |
| [是英雄就下一百层](是英雄就下一百层-课件.html) | 重力、碰撞、滚动、克隆、随机位置、计分 | 按任务分段教学，根据学生进度调整 |
| [太空保卫战](太空保卫战-课件.html) | 按键控制、克隆回收、碰撞计分、广播、游戏状态；选修 Boss 血量 | 4 次基础课＋1 次选修课，每次 45–60 分钟 |

建议先完成《是英雄就下一百层》，再进入《太空保卫战》。项目完成程度不能代替理解程度，可请学生解释或独立改造一段脚本后再决定进度。

## 使用

1. 下载仓库 ZIP 并解压，或克隆仓库。
2. 用现代浏览器打开 `index.html` 选择课程，也可以直接打开任意课件 HTML。
3. 教师带学生观察试玩，随后在 Scratch 中创建自己的作品。

试玩是课件内置的 JavaScript 演示，并非 Scratch 项目文件。参考积木用于手动搭建，不能直接粘贴到 Scratch 中执行。本仓库暂不包含 `.sb3` 文件。

### 演示快捷键

| 操作 | 快捷键 |
| --- | --- |
| 下一页 | → / 空格 / PageDown |
| 上一页 | ← / PageUp |
| 首 / 末页 | Home / End |
| 教师提示 | N |
| 目录 | T |
| 全屏 | F |
| 关闭提示或目录 | Esc |

试玩页会占用游戏控制键：《下一百层》使用左右键；《太空保卫战》使用左右键与空格。试玩期间请用底部翻页按钮或 PageDown 翻页。《太空保卫战》还提供屏幕控制按钮。

## 教学建议

- 先让学生描述观察到的现象，再讨论实现方法。
- 每次只引入一个主要新概念，留出充分动手时间。
- 参考锦囊在尝试后打开，允许先完成基础版。
- 每课末留 5 分钟展示，让学生解释一个原理或一次 Bug 修复。

《太空保卫战》基础版采用穿透激光：击碎 10 颗陨石胜利，撞到或漏掉一颗失败。Boss 版使用受伤冷却扣血，属于简化教学机制。

## 发布到 GitHub

在 GitHub 创建一个空仓库（不预生成 README、许可证或 `.gitignore`），然后在本地目录执行：

```sh
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

将示例用户名和仓库名替换成自己的值。公开仓库后，可在仓库的 **Settings → Pages** 中选择从 `main` 分支的根目录发布；`index.html` 是课程入口。
