第一章先玩，再想

先当一回玩家

不看代码，只观察：这个游戏里到底发生了什么？

① 小人怎么动？

它是自己「自动往下掉」的？还是匀速滑下去？

② 地板动了吗？

到底是谁在动——是小人，还是地板在往上走？

③ 缺口有什么用？

停在缺口旁会怎样？对准缺口会怎样？

带着这三个问题去玩下一页的小游戏。先描述你看到的现象，别急着下结论。
约3分钟。先玩再观察，不提前公布结论。可以让学生口头抢答「谁在动」，答案分歧越大越好——这正是后面讲「相对运动/滚动错觉」的引子。
第一章先玩一玩 · 现场试玩

你能下到第几层？

🦸 是英雄就下一百层
← → 键（或 A D）移动 · 对准缺口往下掉 · 别被顶上的尖刺压扁！
玩三次：第一次随便玩，第二次盯着「缺口」，第三次盯着「顶上的尖刺」。
约5分钟试玩。演示页里，尖刺是「天花板」，越拖越危险——观察学生有没有发现「站在地板上会被托高、不赶紧进缺口就撞头」。用 ← → 移动，空格仍可翻页，避免混淆可在试玩时让学生只用方向键。
第一章把看到的说出来

三个现象，一个都别放过

先说「看见什么」，再想「为什么」

现象① 越掉越快

小人不是匀速往下，而是越来越快——像有什么在一直「拉」它。

这叫「重力」，其实就是一个一直在变大的速度。

现象② 地板往上走

小人停在缺口旁会被地板「托着抬高」，最后被顶到尖刺上。

其实是地板在往上滚，制造了「小人一直往下」的错觉。

现象③ 缺口是出口

只有对准缺口，小人才掉得下去；缺口位置每次都不同。

「每次不同」藏着随机数；「永远有新地板」藏着克隆。

如果小人在同一块地板上一直待着不动，你能猜到它最后会怎样吗？
三个现象对应后面的三大原理（重力、滚动相对运动、克隆+随机）。让学生用自己的话讲，老师只把关键词记在黑板上。这一页是「事实层」，不是「原因层」。
第二章把大游戏拆成小问题

这个游戏有几个「演员」？

再复杂的大作品，也是几个角色各干各的活拼起来的

🦸 小英雄

被玩家控制左右移动；还会自己往下掉。

🪵 地板

一排排不断出现的平台，中间有个缺口。

🗡 尖刺

在屏幕顶端，碰到就游戏结束。

🔢 分数

一个变量，记下小英雄下了多少层。

先把「谁负责什么」写下来——这就是你的任务清单。
约2分钟。让学生自己说出四个角色，比老师直接列出来更好。若学生漏了「分数」，提示：最后那个一直在变的数字是谁？
第二章拆出三张任务卡

每个演员，各有一个「难」

🦸 英雄的难

怎么让人物「一直往下掉」，又能左右躲？

🪵 地板的难

怎么让地板源源不断出现？缺口怎么做到每次不一样？

🎬 最难的点

怎么让「一直往下掉」看起来源源不断，永远不到头？

把这些问题排个队：你觉得应该先解决哪个？为什么？
这里引出「先易后难」的排兵布阵：先做英雄的下落和移动（最简单、最能立刻看到效果），再做地板（克隆+随机），最后拼起来加尖刺和分数。让小朋友体会「拆开再逐个攻破」。
第三章先搞懂为什么

游戏的地基：六个原理

不背步骤，只要懂这六个「为什么」

① 重力

自动掉 = 每回合把 y 减一点，还越减越快。

② 碰撞

只有没踩到地板时才掉；踩到就停。

③ 滚动错觉

地板往上走 = 看起来小人在往下掉。

④ 克隆

画一块地板，复制出无穷多块。

⑤ 随机数

缺口位置随机，所以每一层都不一样。

⑥ 计分与胜负

变量记层数；碰到尖刺就结束。

原理就像积木的说明书——看懂它，积木才会听你的话。
六原理是总纲，后面每页讲深其中一个。这一页先让学生心里有个地图，不要求背。可以在学生做对应任务卡住时，把它翻回来对照。
第三章原理 ①②③ · 让英雄掉下去

重力 + 碰撞 + 滚动错觉

① 重力 = 越掉越快

「自动往下掉」不是一蹴而就，而是用一个变量「下落速度」，每回合让它减小一点，再用它去改变 y 坐标。速度越负，掉得越快。

② 碰撞 = 踩到就停

小人不是永远在掉，而是只有没踩到地板时才掉。踩到地板，立刻把「下落速度」归零。

③ 滚动 = 相对运动

让地板往上动，看起来就等于英雄往下掉。这就是「一直掉不到头」的秘诀。

记住这个最容易搞混的点：英雄大致待在原地，地板源源不断往上滚——而不是让英雄一路掉出屏幕。
原理③是关键，必须讲透：为何「地板往上滚」比「英雄往下掉」聪明？因为地板是无限的，能让舞台永久播放「一直往下」。可用黑板画相对运动示意图。
第三章原理 ④⑤⑥ · 让世界运转起来

克隆 + 随机 + 计分判定

④ 克隆 = 一变无穷

不用画 100 块地板，只画一块，让程序不断复制自己，滚出屏幕后自己消失。

⑤ 随机数 = 缺口不一样

每个克隆体出生时，把自己的 x 设成一个随机数——缺口位置就各不相同。随机必须放在「当作为克隆体启动」里！

⑥ 变量 + 判定 = 有输赢

分数是一个会自己「+1」的变量；碰到尖刺，就停止全部结束游戏。

克隆体各自独立——每个克隆体有自己的「想法」，这是 Scratch 里超级好用的本事。
克隆体是难点：强调「当作为克隆体启动」里的脚本，每一块地板都会各跑一遍；而「当绿旗被点击」里的克隆命令是「母体」在不停地生。可用「打印机」比喻。
第四章动手做 · 第 0 步

先搭台，再唱戏

花 3 分钟把这些「演员」和「道具」准备好

🦸 画一个英雄

新建项目，把小猫换成自己画的小英雄——火柴人、小球、小动物都行。

🪵 画一块地板

新建角色「地板」，画一条宽约 120、高约 18 的横条。

🗡 画一排尖刺

新建角色「尖刺」，画在舞台顶部。

🔢 建两个变量

在「变量」里新建：「下落速度」和「得分」。

先画好后边才有的用。造型「简单但清楚」就好，你自己喜欢最重要。
约3分钟。变量名建议就用「下落速度」「得分」，和后面积木一致，减少学生混淆。地板要足够宽，能横跨游戏区。
第四章任务 1

让英雄「越掉越快」

原理① 重力
怎么让英雄像被地心引力拉住一样，越掉越快地往下走？

① 先静止

把「下落速度」一开始设为 0。

② 每回合更快

在「重复执行」里，让「下落速度」增加一个负数（比如 -1）。

③ 用它来动

把 y 坐标增加「下落速度」。速度越负，掉得越快。

🧰 卡住了？点开锦囊
参考积木 · 英雄角色
当 🟢 被点击
将 下落速度 设为 0
重复执行
将 下落速度 增加 -1
将 y 坐标 增加 下落速度

试着把 -1 改成 -0.5 或 -2，感受不同「重力强度」。

关键认知：重力不是「往下移动10步」，而是「速度在变大」+「用速度去移动」。让学生先自己摆，摆不出再给锦囊。做完后问：为什么是「增加 -1」而不是「增加 -10」？
第四章任务 2

让英雄能左右躲

怎么用 ← → 键控制英雄，躲开危险？

向右

用事件积木「当按下 → 键」，让 x 坐标增加。

向左

把 x 坐标增加一个负数就行。

🧰 卡住了？点开锦囊
参考积木 · 英雄角色
当按下 → 键
将 x 坐标 增加 10
当按下 ← 键
将 x 坐标 增加 -10

进阶：加上「碰到边缘就反弹」或限制 x 范围，别让英雄跑丢。

这页最简单，很快过。可顺便问：为什么「向左」用负数？复习坐标概念。完成的学生可挑战「加一个不让英雄跑出屏幕的限制」。
第四章任务 3

踩上地板就不掉

原理② 碰撞
现在英雄会一路穿地板掉到底。怎么让它踩到地板时停下来？
顺序是重点：先下落，再检测。检测到碰到地板，立刻把「下落速度」设为 0。
想想看：如果先检测、再下落，会闹出什么 bug？
🧰 卡住了？点开锦囊
参考积木 · 英雄角色（叠加在任务1上）
当 🟢 被点击
将 下落速度 设为 0
重复执行
将 下落速度 增加 -1
将 y 坐标 增加 下落速度
← 先动，再检测
如果 碰到 地板 ? 那么
将 下落速度 设为 0

此时地板是静止的，英雄会稳稳踩住。下一任务再让地板动起来。

强调「先动后检测」——不然英雄会「检测时还没踩到，动完又穿过去了」。这是很常见的 bug 源，值得让学生亲手撞一次再明白。完成标准：不插键盘，英雄停在第一块地板上。
第四章任务 4

地板源源不断 + 随机缺口

原理③ 滚动 + ④ 克隆 + ⑤ 随机

滚动

地板每回合把 y 坐标增加一个正数（往上走）。

克隆

一个「主控脚本」每隔一小段时间就克隆自己；克隆体向上移动，出屏幕后删除自己。

随机缺口

每个克隆体一出生就把 x 设成随机数，缺口位置就各不相同。

随机数该放在「当绿旗被点击」里，还是「当作为克隆体启动」里？
🧰 卡住了？点开锦囊
参考积木 · 地板角色（两个脚本）
// 脚本一 · 母体：负责不停「生」地板
当 🟢 被点击
重复执行
克隆 我自己
等待 0.9 秒
// 脚本二 · 克隆体：每块地板自己的行为
当作为克隆体启动时
移到 x: 在 -180 到 180 之间取随机数 y: 200
重复执行
将 y 坐标 增加 2
如果 y 坐标 ＞ 250 那么
删除此克隆体

要点：随机 x 要放在「当作为克隆体启动」里，每块地板才会不同；出屏幕要及时删除，否则电脑会越来越卡。

这是最硬的一页，建议拆两步：先让地板克隆+滚动（无缺口），跑通后再加随机缺口。随机必须放「当作为克隆体启动」——可让两个学生分别放两处对比，效果一目了然。
第四章任务 5

计分：下了几层？

原理⑥ 计分
英雄每成功下去一层，「得分」就该 +1。怎么算「下去一层」？

放一条「计分线」

新建一个隐藏角色「计分线」，放在英雄下方一点点。

只加一次

地板克隆体：碰到计分线就「得分 +1」，但不能再重复加。

🧰 卡住了？点开锦囊
参考积木 · 地板克隆体（加在脚本二里）
当作为克隆体启动时
将 已计分 设为 0
// 注：已计分 是「仅限此克隆体」的私有变量
如果 碰到 计分线 ? 那么
如果 已计分 ＝ 0 那么
将 得分 增加 1
将 已计分 设为 1

「只加一次」这个思路，几乎每个计分游戏都会用到。

难点是「只加一次」：私有变量「已计分」做标记，防止分数狂涨。可先故意让学生不加标记，看分数疯狂飙，再引出卖点。这是很好的「先踩坑再解决」。

第四章bug 是礼物

常见 bug 诊所

作品跑不对，别慌——先猜猜每个问题出在哪

① 英雄穿过了地板

下落速度太快，一帧就「跳」过了地板。改小速度（如 -0.6），或把地板画厚一点。

② 缺口都在同一个位置

随机 x 放错位置：要放在「当作为克隆体启动」里，而不是只算一次。

③ 得分疯狂飙升

忘了「只加一次」的判断，地板每帧都在加分。

④ 越来越卡

克隆体出屏幕后没删除，越积越多。记得「出屏幕就删除此克隆体」。

每个 bug 背后都藏着一个原理——看懂 bug，= 原理真的会了。
这页留给学生自查。老师巡回时，先问「你猜是哪一步的问题」，再引导定位，不直接替学生改。
第五章加上你的创意

让它变成「你的」游戏

核心做好了，现在轮到你发挥

🎵 音效

下落「嗖～」，加分「叮！」，结束「轰——」。

⚡ 越下越刺激

让滚动速度、重力随得分越来越快，第 100 层像过山车。

🪙 道具

金币、弹簧、加速鞋、无敌护盾……每种道具一个效果。

🏆 排行榜

把最高分存起来，和同学比谁更「英雄」。

先挑一个做，做好再说下一个——小步走，才走得远。
拓展自愿、不限数量，但要「一次一个」，避免贪多做成半成品。有余力做「越下越快」的学生，本质上是在改造「重力」和「滚动速度」，是对原理①③的活学活用。
第六章检查 + 回顾

作品自检清单

全部打勾，才算真正过关
  • 英雄能自动向下掉，且越掉越快（重力）
  • ← → 键能左右移动，不会跑出屏幕
  • 踩到地板会停，没踩到会继续掉（碰撞）
  • 地板源源不断出现，且带随机缺口（克隆 + 随机）
  • 能计分（变量）
  • 碰到尖刺会游戏结束（判定）
让学生逐条自己点检，老师抽查。可以把自检清单投影，全班一起核对。有问题的回到对应章节再看原理。
第六章原理回顾

一张表，装下六个原理

现象背后原理对应积木
越掉越快重力 = 速度越变越负改变「下落速度」+ 改变 y
踩住不掉碰撞 = 碰到地板就停碰到…？ + 如果…那么
一直往下滚动 = 地板往上走相对运动
地板无穷克隆 = 不断复制克隆自己 + 当作为克隆体启动
缺口不同随机数的位置在 … 之间取随机数
输赢有数变量计分 + 判定结束变量 + 停止全部
总结用。让学生闭着眼睛回忆六个原理各对应哪个现象，随口点名抽查。最后把「六任务清单」复制给学生作为课后作业。
第六章收束

今天带走三句话

会拆

再大的游戏，也能拆成几个小问题。

懂原理

重力、碰撞、滚动、克隆——都是自己能说清的道理。

自己做

作品是我亲手搭起来的，卡住了我会查原理。

不是「照着抄一遍」，
而是「我能讲清楚，为什么我的英雄会越掉越快」。
这套办法还能做：接金币、跳跳板、躲障碍——先拆、再懂原理、最后动手。
